# 《人生如戏》Life is a Stage

> 人生模拟 × 财商教育 × 卡牌决策游戏

每个人都是自己人生的主角，你的每一个选择，都在书写剧本的下一幕。

## 游戏简介

《人生如戏》是一款基于月度现金流决策的人生模拟游戏。玩家从6种不同的人生起点出发，通过学习技能、投资理财、应对人生事件，在有限的人生中实现从生存到财务自由的跨越。

**核心问题**：哪些该学习，哪些该进一步发展？

## 技术栈

- HTML5 + CSS3 + JavaScript (ES6+)
- 纯前端，无后端依赖，可直接在浏览器运行
- 响应式设计，优先移动端体验
- localStorage 本地存档

## 核心玩法

### 游戏循环

```
开场结算 → 看现金流报表 → 剧本决策 → 戏份事件 → 幕落复盘 → 下一月
```

### 6种人生剧本

| 剧本 | 年龄 | 初始月薪 | 初始储蓄 | 初始负债 | 难度 |
|------|------|----------|----------|----------|------|
| 应届生 | 22 | 4,000 | 5,000 | 0 | 简单 |
| 职场新人 | 25 | 6,500 | 15,000 | 5,000 | 普通 |
| 资深职场 | 30 | 12,000 | 50,000 | 20,000 | 普通 |
| 创业者 | 28 | 8,000 | 30,000 | 50,000 | 困难 |
| 自由职业 | 26 | 5,000 | 20,000 | 0 | 困难 |
| 负债上岸者 | 27 | 7,000 | 2,000 | 80,000 | 地狱 |

### 4系技能树（该学习 / 该发展 双轨制）

- **职业系**：专业认证、管理能力、职业深度、行业人脉
- **财商系**：基金定投、股票投资、房产投资、被动收入
- **副业系**：自媒体、技能接单、电商运营、知识付费
- **生活系**：健身习惯、时间管理、情商沟通、亲密关系

每个技能有「学习」和「发展」两个阶段，学习解锁基础效果，发展获得进阶加成。

### 四阶段财务成长

1. **生存阶段**：月光或负债，首要目标是活下去
2. **安全阶段**：有3-6个月应急金，开始学习投资
3. **自由阶段**：被动收入覆盖支出，拥有选择权
4. **财富阶段**：资产持续增值，实现人生价值

## 如何运行

### 方式一：直接打开

用浏览器直接打开 `index.html` 文件即可开始游戏。

### 方式二：本地服务器

```bash
cd life-is-a-stage
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 游戏操作

- **下一月**：推进游戏时间，结算当月收支
- **技能树**：查看和学习/发展技能
- **投资**：进行投资、取款、提前还债
- **存档**：游戏自动存档，可在主菜单读取

## 设计理念

1. **选择即人生**：每个决定都有机会成本，没有完美的选择
2. **延迟满足**：学习和投资的回报需要时间，急功近利往往失败
3. **风险与收益**：高收益伴随高风险，分散投资是王道
4. **健康第一**：身体和心理健康是一切的基础
5. **人生不只有钱**：幸福、关系、成长同样重要
