# 🎭 人生如戏 (Life is a Stage)
> 每个人都是自己人生的主角——你的每一个选择，都在书写剧本的下一幕。

## 🚀 v0.2 核心迭代：从"教育软件"到"人生重开模拟器"

**核心验证指标：重开率** — 玩家玩完第一局后，会不会想"再开一局，换个选择试试"？

### 新增三大核心机制

1. **🚦 关键年龄不可逆人生岔路**
   - 22/25/30/35岁等关键年龄，强制触发人生方向选择
   - 每个选择都有明确的机会成本，后果延迟兑现，不可逆
   - 选择后解锁对应的人生路线（创业线/家庭线/学术线等）

2. **🎭 平行人生钩子（结局系统）**
   - 游戏结束时，根据你本局错过的选择，生成2-3个"如果当时"的遗憾片段
   - 例如："你30岁选择了买房。如果当年把钱拿去投资，现在可能资产已经翻倍了"
   - 激发"再开一局试试那个选择"的欲望

3. **🎲 半确定性事件系统**
   - 关键年龄岔路固定触发（玩过一次就知道）
   - 条件触发事件（负债>10万必触发催收等）
   - 半随机事件（满足条件后有概率触发）
   - 让玩家"越玩越懂"，上一局的经验可以预测下一局的事件

### 设计理念

> **失败信号**：玩家玩完想"哦，原来财务自由需要存钱"，然后退出。→ 这是教育软件。
>
> **成功信号**：玩家玩完想"操，我刚才不该买房"、"再来一次我不买房"、"等等我这次试试创业"，然后连续开三局。→ 这才是人生的"存档/重开/What If"模拟器。

## 游戏简介
《人生如戏》是一款**人生模拟 × 财商教育 × 卡牌决策**游戏。玩家通过每月的财务决策、技能学习和人生选择，体验"选择的长期后果"——今天学什么、投什么、拼什么，十年后会变成什么样？

## 核心特色
- 📊 **现金流即玩法**：可视化现金流沙盘，不是事后看报表，而是基于报表做决策
- 🎯 **双轨制技能树**：明确区分"该学习（从0到1）"和"该发展（从1到10）"
- 🎭 **四幕完整人生**：登台→打拼→收获→谢幕，覆盖18-80岁
- 🔄 **重开乐趣**："如果当时选了另一条路会怎样"是核心驱动力
- 💡 **玩中领悟**：不是教你"应该怎样"，而是让你亲眼看见"选择了会怎样"

## 技术栈
- HTML5 + CSS3 + JavaScript (ES6+)
- 纯前端，无需后端，可直接在浏览器运行
- 响应式设计，移动端优先

## 如何运行
1. 克隆仓库到本地
2. 用浏览器打开 `index.html`
3. 或者启动本地服务器：`python3 -m http.server 8080`，然后访问 `http://localhost:8080`

## 游戏内容
- **6种人生剧本**：应届生、职场新人、资深职场、创业者、自由职业、负债上岸者
- **4系26个技能**：职业系、财商系、副业系、生活系（18可学习+8可发展）
- **23个事件**：15随机+8里程碑
- **4阶段财务成长**：求生→安全→稳定→自由
- **5种结局**：财务自由型、事业成功型、家庭幸福型、自由人生型、破产人生型
