# 🎭 人生如戏 (Life is a Stage)

> **一款可以重新体验“另一种人生”的人生决策模拟器。**

你的每一个选择，都在书写剧本的下一幕。

## v1.0 方向：从人生游戏到人生推演器

核心循环：

```text
选择 → 后果 → 人生变化 → 如果当时 → 重新推演
```

**北极星指标：重开率。**

玩家第一局结束后，不应该只得到一个分数，而应该产生一个问题：

> “如果当时我选了另一条路呢？”

## v1.0 核心系统

### 1. 人生因果引擎

从旧模式：

`选择 → 直接修改属性`

逐步升级为：

`选择 → 行为 → 状态 → 持续影响 → 后续机会 → 延迟结果`

### 2. 人生时间线

记录真正值得回看的节点：

- 人生开幕
- 重大选择
- 重大事件
- 人生转折
- 人生终章

### 3. 平行人生

人生结束后可以选择关键节点：

`保留过去 → 修改选择 → 重新模拟 → 形成另一种人生`

### 4. 人生路线

人生路线不再只是“进入/未进入”，而是由长期行为逐渐形成：

- 事业
- 家庭
- 财富
- 自由
- 冒险
- 健康
- 稳定

## 当前实现

v1.0 已先通过演化适配层接入旧核心，不推倒现有 GameState：

- `js/game/CausalEngine.js`：因果记录、持续后果容器
- `js/game/LifeTimeline.js`：人生时间线与分叉数据
- `js/game/V1EvolutionAdapter.js`：兼容旧系统的 v1.0 接入层
- `docs/V1_PRODUCT_DIRECTION.md`：产品长期方向与开发原则

这一步的目的不是假装已经完成完整因果模拟，而是先建立稳定的数据层，为后续迁移旧 effects 做准备。

## 当前原则

**暂停无上限增加事件、技能和结局。**

优先把已有系统连接成真实因果：

```text
技能 → 职业 → 收入
收入 → 现金流 → 风险承受能力
房产 → 首付 → 房贷 → 流动性 → 自由度
婚姻 → 家庭责任 → 支出 → 时间
健康 → 工作效率 → 收入 → 幸福
人脉 → 机会 → 职业/创业路径
```
