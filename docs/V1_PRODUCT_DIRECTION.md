# 《人生如戏》v1.0 产品方向

## 一、重新定位

> 一款可以重新体验“另一种人生”的人生决策模拟器。

游戏的核心不是收集属性、赚钱或刷结局，而是让玩家体验：

**选择 → 后果 → 人生变化 → 如果当时 → 重新推演**

## 二、v1.0 北极星指标

### 第一指标：重开率

玩家结束第一局后，是否主动重新开始并改变关键选择。

### 第二指标：关键节点回溯率

玩家是否愿意回到某一个重大人生节点，尝试另一条路线。

### 第三指标：单局重大选择数

不是追求点击量，而是让玩家产生足够多真正影响后续人生的选择。

## 三、四个核心系统

### 1. 因果引擎

旧模式：

`选择 → 直接修改属性`

目标模式：

`选择 → 行为 → 状态变化 → 持续影响 → 后续机会 → 延迟结果`

一个重大选择必须能够影响未来，而不是只产生一次性的数值变化。

### 2. 人生时间线

只记录值得回看的节点：

- 人生开幕
- 重大选择
- 重大事件
- 人生转折
- 终章

时间线是未来“我的这一生”和“平行人生”的统一数据基础。

### 3. 平行人生

人生结束后允许玩家选择一个关键节点：

`保留过去 → 修改关键选择 → 从节点重新模拟 → 形成第二人生`

最终支持多条人生同时比较。

### 4. 人生分叉

人生路线不应该只是 true/false 标记，而应该逐渐积累路线倾向。

示例：

- 事业
- 家庭
- 财富
- 自由
- 冒险
- 健康
- 稳定

玩家不是“进入某路线”，而是在长期行为中逐渐成为某种人。

## 四、AI原则

AI不负责决定游戏规则。

模拟器负责：

- 状态
- 规则
- 概率
- 因果
- 结果

AI负责：

- 解释
- 复盘
- 叙事
- 反事实分析
- 人生报告

## 五、内容原则

暂停无上限增加事件、技能和结局。

优先把已有系统之间建立真实因果：

- 技能 → 职业 → 收入
- 收入 → 现金流 → 风险承受能力
- 房产 → 首付 → 房贷 → 流动性 → 职业自由度
- 婚姻 → 家庭责任 → 支出 → 时间
- 健康 → 工作效率 → 收入 → 幸福
- 人脉 → 机会 → 职业/创业路径

## 六、长期产品路线

### Phase 1：人生模拟游戏

完成稳定的因果模拟与多结局。

### Phase 2：平行人生

实现关键节点回溯和人生对比。

### Phase 3：AI人生顾问

根据真实模拟结果解释“为什么会走到这里”。

### Phase 4：人生挑战

相同初始条件，由不同玩家做选择，比较不同人生结果。

### Phase 5：UGC剧本

玩家和AI创建人生剧本，其他玩家进行挑战。

### Phase 6：人生模拟平台

支持用户输入自己的现实状态，模拟不同未来方案。

## 七、明确不做

当前阶段不优先：

- 单纯增加事件数量
- 单纯增加技能数量
- 抽卡
- 复杂多人在线
- 重资产美术
- 复杂商城

原因：项目当前最大的瓶颈不是内容量，而是因果深度和重开价值。
